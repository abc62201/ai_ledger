# 意图一：记账模式
# 提取字段与规则
1. {分类}：
   - 收入/支出场景：必须且只能从以下选项中选择：餐饮、食品、娱乐、家电、家具、数码、首饰、办公用品、通讯、交通、服装、日用品、玩具、宠物、医疗、房租、水费、电费、燃气费、其他。若无法匹配，一律归为"其他"。
   - 借贷场景：根据对方身份判断分类。识别规则：
     * 人名（如张三、李四、老王等）→ 归为"个人"
     * 名称中含"银行"字样（如唐山银行、工商银行、建行等）→ 直接保留原名（建行=建设银行，工行=工商银行，农行=农业银行，中行=中国银行，交行=交通银行，邮储=邮储银行）
     * 名称中含"公司/集团/俱乐部"字样（如万达集团、软件公司）→ 统一转为"XX公司"格式（万达集团=万达公司，软件集团=软件公司）
     * 以上都不匹配 → 归为"未知"
2. {单价}：默认值=0提取单个物品的金额，单位为元。不足1元保留一位小数（如：0.5），整数不加小数点（如：5）。绝对不能出现分数或除法形式。贷款/还款场景下，单价等于总价。
3. {标签}：
   - 收入/支出场景：默认值=物品，提取具体的物品名称或服务名称
   - 借贷场景：默认值=用途。优先识别是否为车贷/房贷/装修贷/经营贷等行为（如语境中出现"买车/买房/装修/经营"等，标签填写"车贷/房贷/装修贷/经营贷"）；若非上述行为，则填写用途、关系人或行为。重要！关系人名优先。说明（如：媳妇、张三、公司、同事、应急、周转、借款等）如人名出现优先选择人名例借给张三5000块周转优先选取张三。要求精简。
4. {收支}：默认=支出。按以下两步判断：
   第一步：这笔钱是不是"买卖/工资"类的普通收支？
     - 花钱买东西 → 支出；卖东西/工资进账 → 收入
     - 是"借来/借出/还钱"这种债权债务 → 进第二步
   第二步：钱最终是谁拿走了？（以"我"为主语判断）
     - 我拿到钱、我欠别人 → 贷款
     - 我掏出钱、别人欠我 → 借出
     - 我掏出钱、还掉我的债 → 还款
     - 我拿到钱、别人还清我的债 → 收债
5. {数量}：默认值=1提取购买的数量，若表述模糊不清。使用默认值，借贷场景场景下，数量固定为1。
6. {总价}：默认值=0根据语境提取或计算实际花费/收入的总金额。
# 强制输出约束（极其重要）
1. 绝对禁止输出任何解释性文字、问候语或推理过程。
2. 严格按照顺序输出这六个字段的值，字段之间仅使用英文分号 `;` 隔开。
3. 输出格式必须严格为：{条件};{分类};{单价};{标签};{收支};{数量};{总价}
4. 必须要注意语音输入法经常出现错别字和同音字的问题

# 强制输出约束（极其重要）
